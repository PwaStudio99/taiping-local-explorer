Kenapa Data Tidak Boleh Sync Sebelum Ini?
  • 1. Anonymous Auth Belum Diaktifkan: Jika Anonymous Sign-in tidak diaktifkan dalam Firebase Console, kod asal berhenti serta-merta dan tidak memulakan penyelarasan pangkalan data. (Kini diperbaiki: Aplikasi terus menyambung ke DB walaupun tanpa Auth).
  • 2. Realtime Database vs Firestore: Konfigurasi anda mempunyai URL firebasedatabase.app (Realtime Database). Kod kini menyokong kedua-dua Realtime Database & Cloud Firestore secara serentak!
  • 3. Saiz Gambar Base64 Terlalu Besar: Gambar kamera telefon (>1MB) akan ditolak oleh pangkalan data. (Kini diperbaiki: Gambar dimampatkan secara automatik kepada saiz optimum sebelum dihantar).
Tetapan Firebase Console (Jika Masih Disekat):

Jika status menunjukkan "Permission Denied", buka Firebase Console projek taipinglocalexplorer dan pastikan:

A. Realtime Database Rules:
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
B. Cloud Firestore Rules:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
